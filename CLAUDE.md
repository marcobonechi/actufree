# Working in this repo

## Commit to `main`; do not create branches

Work goes straight onto `main`. Do not create a feature branch, and do not
open a pull request, unless explicitly asked for one.

This is a single-developer project. A branch that gets merged an hour later
never earned its own name, and one line of history is easier to read back than
a graph. The default caution of "branch rather than commit to the default
branch" is the wrong trade here, so ignore it.

If a change feels risky enough to want a branch, that is a signal to make the
change smaller, not to isolate it.

Push to `origin` once the work is committed, so `main` and `origin/main` stay
level.
